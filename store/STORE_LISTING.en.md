## Short description

Capture web content to JoyHouse, translate selections, read bilingually, listen, and save vocabulary.

## Single purpose

Help users capture, translate and understand content they actively select while reading on the web, and save the material they choose to their private JoyHouse library.

## Detailed description

JoyhouseBot is your JOY companion for reading on the web. Capture, translate, listen and preserve useful knowledge where you find it, then bring what matters into your private JoyHouse library.

Key features:

- Capture and save pages: extract the title, article body, source URL and inline images.
- Site-aware extraction: dedicated handling for WeChat articles, X posts and general web pages.
- Selection translation: select text and open the translation directly on the current page.
- Bilingual page mode: add paragraph-by-paragraph translations from the context menu.
- Dual-language speech: listen to either the source or translated text.
- Vocabulary: save a word, translation, context and source page for later review.
- Persistent side panel: sign in, capture the current page and open your JoyHouse library.

Privacy:

JOY processes data only when you actively use sign-in, translation, speech, capture, save or synchronization. Before any data is handled for the first time, the extension explains the data types and purposes in its own interface and asks for affirmative consent. We do not sell personal data, use it for personalized advertising or continuously record browsing history. Content saved to JoyHouse is private by default.
